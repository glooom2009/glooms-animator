# Gloom's Animator

**Gloom's Animator** is a lightweight 2D animation application designed to make animation accessible, creative, and easy to use.

Create animations, build rigs, work with sound, and experiment with custom lighting — all in one application.

## Features

Gloom's Animator aims to provide a powerful animation experience with the freedom of a free alternative to software like Adobe Animate.

- **2D Animation** — Create animations with an intuitive workflow.
-  **Rigging System** — Build rigs to animate characters and other objects.
-  **Sound Studio** — Work with audio for your animations.
-  **Custom Lighting** — Experiment with lighting to enhance your scenes.
-  **Lightweight** — Designed to provide an accessible animation experience.
-  **Easy to Use** — A user-friendly workflow for beginners and experienced animators.
-  **Creative Freedom** — Bring your characters, ideas, and stories to life.

Animation software should give creators the freedom to experiment without making the process unnecessarily complicated.

Gloom's Animator aims to combine useful animation tools with a lightweight, approachable experience.
